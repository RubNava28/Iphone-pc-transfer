# Changelog

## 1.0.0 - 2026

Initial GitHub-ready release.

### Added

- Local PC to iPhone and iPhone to PC transfer.
- QR access.
- Optional password and temporary code.
- Multi-language selector.
- Drag and drop support.
- Multiple file upload from iPhone.
- iPhone camera capture.
- PDF preview in Safari.
- Image gallery.
- Transfer queue and cancellation.
- File search, sorting, rename, delete and selection actions.
- History, connected devices, live activity and statistics.
- Automatic date-based folders for received files.
- Previous-session summary.
- Private mode.
