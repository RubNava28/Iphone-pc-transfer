# Contributing

## Code standards

- Keep file, network and security operations explicit and documented.
- Avoid hard-coded personal paths.
- Validate browser input before saving files.
- Keep user-facing messages professional and concise.
- Do not commit generated executables, runtime transfer files or local password files.

## Workflow

1. Create a branch for each change.
2. Test locally on a private network.
3. Update documentation if behavior changes.
4. Open a pull request with a clear description.
