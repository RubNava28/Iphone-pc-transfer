# Installation

## Requirements

- Windows 10 or Windows 11.
- Python 3.10 or later for source execution.
- iPhone and PC connected to the same private Wi-Fi network.

## Install dependencies

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Run from source

```bash
python run.py
```

## First launch

1. Open the application.
2. Confirm or change the interface language.
3. Configure password or temporary code if required.
4. Start the server.
5. Scan the QR code from the iPhone camera or open the displayed local URL in Safari.
