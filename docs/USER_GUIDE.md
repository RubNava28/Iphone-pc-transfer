# User guide

## Start the server

1. Open the application.
2. Review transfer, language and security options.
3. Press **Start server**.
4. Open the displayed URL on the iPhone or scan the QR code.

## PC to iPhone

- Use **Add files** or drag files into the transfer area.
- Open the web page in Safari.
- Download the files from the iPhone.

## iPhone to PC

- Use the upload form from Safari.
- For photos or videos, use the camera capture section.
- Received files are stored under a date-based folder.

## PDF preview

PDF files can be opened in Safari without forcing a download.

## Security

Use password or temporary-code protection when other devices share the same
network.
