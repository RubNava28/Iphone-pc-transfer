# Security policy

## Intended use

Use this application only on trusted private networks. The application starts a
local web server that can be accessed by devices on the same network.

## Recommendations

- Enable password or temporary-code access on shared networks.
- Allow firewall access only on private networks.
- Do not use the server on public Wi-Fi.
- Do not commit runtime files, passwords or local configuration files to GitHub.
- Review received files before opening them.
- Use private mode for temporary or sensitive transfers.
